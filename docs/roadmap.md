# 开发路线

这个库要解决的问题是：拿到一份真实或模拟市场的数据后，按清晰、可复核的口径检查常见金融统计事实，并生成适合人阅读的报告。

目前完成了 Conda 环境、价格 CSV 输入、时间采样和独立 HTML 报告。第 1–6、8–11 项已有描述性诊断，合成序列及边界测试覆盖这条流程。以下 11 项是完整目标，第 7 项与正式统计检验仍待实现。长范围 ACF 图并不构成长记忆或幂律衰减检验。

## 评估范围

以 Cont 的 11 项事实为覆盖清单。每项在实现前明确公式、数据要求、图形和解释边界。

| 事实 | 希望回答的问题 |
| --- | --- |
| 收益缺乏自相关 | 过去的涨跌方向能否线性预测后续方向？ |
| 厚尾 | 极端收益是否比相同尺度的高斯参照更常见？ |
| 涨跌不对称 | 上涨和下跌的统计特征是否不同？ |
| 聚合高斯化 | 时间间隔增大后，收益分布是否更接近高斯？ |
| 间歇性 | 市场是否交替出现平静与剧烈活动？ |
| 波动聚集 | 大幅变化之后是否更容易继续出现大幅变化？ |
| 条件厚尾 | 调整时变波动后，收益是否仍表现出厚尾？ |
| 绝对收益自相关缓慢衰减 | 波动的相关性能持续到多长尺度？ |
| 杠杆效应 | 过去的收益与未来波动是否存在不对称关系？ |
| 成交量与波动相关 | 活跃交易是否伴随更大的价格变化？ |
| 时间尺度不对称 | 粗尺度与细尺度波动之间的预测关系是否不对称？ |

覆盖不等于给每项一个简单的通过/失败标签。有些事实依赖市场、资产和数据频率；缺少成交量就无法直接评估量价关系。长记忆与幂律也不能仅凭一张直线拟合图确认。

## 实施顺序

1. **确定评估约定。** 为每项建立可审阅的方法表，核对文献与可复用实现，区分必需数据和可选扩展。
2. **建立公共基础。** 输入检查、时间处理、收益计算、结果结构、图形与报告模板。
3. **逐项实现和验证。** 先以手算及合成数据确认统计行为，再连接真实数据。
4. **多市场验证。** 分别分析已有 EBS 高频数据、FRED 日频数据，之后补充其他资产类别。不同频率不直接混为同一评价。
5. **准备开源。** 完善 API、示例、自动化测试、文档、许可证和发布流程。

每一步交付可检查的结果，不先堆一套无法验证的指标。

## 输出形式

正文报告围绕“看什么—结果如何—能说明什么”组织；技术细节放附录。各条模拟路径分别展示，结论同时说明跨路径的一致性与差异。统计量、采样设置和不可计算原因另行结构化导出。

当前入口是 `fsf analyze INPUT --output DIR`，支持采样频率、时区、价格沿用时长等配置。输入字段先采用固定规范；真实数据源适配器和完整评估模块将逐步增加。

## 数据与项目关系

本项目位于用户主目录下，与 fx-simulation 并列。已有数据只通过外部路径引用；新的库可以服务外汇、股票及其他金融市场。仓库只保存代码、文档和可公开的小型合成测试数据。
