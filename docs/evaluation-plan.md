# 我们准备怎样评估金融市场

**目标：输入一份市场数据，得到一份可以直接阅读、还能追溯计算方法的报告。** 以下是完整覆盖设计，不能当作完整检验已经完成。当前第 1–6 项已有描述诊断：分布、三类 ACF、涨跌不对称、多尺度聚合、滚动 RMS 与波动片段；尚无置信区间与正式检验。第 7–11 项待实现。涨跌不对称目前没有首达时间或最大回撤检验。可运行入口见[使用指南](usage.md)。

覆盖清单以 [Cont（2001）](https://doi.org/10.1080/713665670) 的 11 项事实为基础。还参考 [Revisiting Cont’s Stylized Facts（2024 预印本，第 2.1 节及第 4 节）](https://arxiv.org/html/2311.07738v2)：同一个市场不一定同时表现出所有事实。因此报告应描述实际结果，而不是强行给出“11 项全部通过”。

下面的计算和展示方案是本库的工程设计，不宣称是 Cont 指定的一套统一检验标准。

## 每一项会看到什么

| 项目 | 首版计算与展示 | 怎么理解结果 |
| --- | --- | --- |
| 1. 收益自相关 | 收益 ACF，标出真实时间间隔；给出相关系数和不确定性 | 接近零表示该尺度上线性相关弱，不等于收益完全独立 |
| 2. 厚尾 | 每条路径的密度图、超额峰度，以及尾部概率诊断 | 峰度为正是线索；判断远尾还要看极端观测和样本量 |
| 3. 涨跌不对称 | 左右尾概率、相同概率下涨跌幅分位数、偏度；另看回撤与上涨段 | 分布不对称与路径回撤不是同一个指标，不互相替代 |
| 4. 聚合高斯化 | 在几个预先指定的时间间隔上，比较标准化分布、峰度和分位数偏离 | 看随尺度的变化趋势，不要求某个间隔就变成正态 |
| 5. 间歇性 | 收益与滚动波动图；补充大幅变化的占比和连续区段 | 描述平静与剧烈时段交替；单凭图形不自动判定显著 |
| 6. 波动聚集 | 绝对收益和平方收益的 ACF，逐路径展示 | 连续多个滞后有正相关，支持波动持续性 |
| 7. 条件厚尾 | 拟合波动模型后，再看标准化残差的密度、峰度和尾概率 | 检查控制时变波动后是否还存在厚尾；拟合失败要明确报告 |
| 8. 波动相关的慢衰减 | 延长绝对收益 ACF 的观察范围，比较多个区段和拟合窗口 | 几个正相关点不够证明长记忆，直线拟合也不够 |
| 9. 杠杆效应 | 过去收益与未来波动的相关曲线，并展示相反时间方向 | 关注方向与持续范围；外汇倒数报价会改变收益符号 |
| 10. 成交量与波动 | 同一时间区间的成交量与波动相关、分组图 | 需要真实成交量；报价次数不能默认当作成交量 |
| 11. 时间尺度不对称 | 比较粗尺度波动对未来细尺度波动，以及反方向的相关性 | 两种时间方向的差异才是重点，不是价格缩放拟合斜率 |

**正文保持干净。** 一项先回答“这张图看什么”，随后展示主要图和两三句结论。密度图默认不叠加正态曲线；需要高斯对照的 QQ 图、尾部诊断和计算细节放可展开的附录。报告可以按资产或路径切换，但不默认混合样本或平均曲线。

## 输入数据先统一

基本输入是时间、价格、资产标识；模拟数据还要有路径标识。成交量、交易时段、报价方向和价格类型作为明确字段或配置。

- 默认使用非重叠的固定时间收益，频率由数据能力和研究目的决定。高频可比较 1 分钟、5 分钟等；日频不会被插值成分钟数据。
- 成交价、买卖中间价、复权收盘价分别记录，不能悄悄混用。
- 不用未来价格填缺失。不在周末、闭市和数据缺口中制造连续零收益。
- 每项输出实际样本数、覆盖时段、采样频率及不可计算原因。
- 多路径先分别分析，再报告有多少条出现同一现象。原始路径都保留，不挑样本。

## 检验如何避免“看图说话”

每项同时提供描述性统计和适用的不确定性估计。分布的区间估计要考虑时间依赖；独立高斯白噪声只是一种参照，不能代替所有检验的零假设。大量滞后或多资产比较需说明多重比较处理。

报告区分“已计算”“数据不足”“不适用”和“计算失败”；科学结论另行说明。不会把一个很小的 p 值自动翻译成某种市场机制，也不会把 p 值不显著翻译成证明不存在。

## 怎么验证这个库

先用已知性质的数据确认每个模块：独立高斯收益、独立厚尾收益、有方向相关的序列、波动聚集序列，以及缺失值和零方差边界。之后再用真实数据验证报告是否易读、数据处理是否正确。

已有 EBS 和 FRED 可作为首批真实案例，分别服务高频与日频分析。完成后补充股票或其他资产。它们都只是外部输入，不会连同原始数据上传到开源仓库。
