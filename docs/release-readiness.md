# 首版交付与公开前决定

首版提供的是可复核的诊断工具：输入价格及可选区间成交量，一条命令生成可读报告和数值。它不把不同市场强行评为“十一项全部通过”。当前候选为 `0.13.0.dev0`，仍保持私有；最终验收状态见 [进度页](status.md)。

## 开会怎样演示

在专用 Conda 环境运行 `fsf demo --output /tmp/fsf-meeting-demo`，下载并打开 `report/index.html`。先切换独立高斯与 GARCH 路径，看收益相关和波动相关的区别，再看条件波动过滤前后的峰度。最后展示量价演示 `fsf demo --kind activity --output /tmp/fsf-meeting-activity`。两个示例都明确标为合成数据，不冒充真实市场。

真实数据的八份验证结果见 [验证摘要](real-data-validation.md)。演示真实行情前先核对使用权；仓库和安装包不附带这些行情。

## 已准备的交付物

- 安装入口、包内示例、公共 Python API、单文件 HTML 与逐路径 CSV/JSON。
- 十一项方法及限制、依赖环境、真实数据字段说明、源码包和 wheel 验收程序。
- GitHub 自动化测试、变更记录、参与开发说明、引用文件与依赖来源清单。
- 已知限制：未内置交易日历或日内季节调整，未验证所有平台；统计区间依赖假设，不能自动证明长记忆或总体幂律尾。

## 公开前只需确认这些发布决定

1. **许可证和署名。** 候选建议为 MIT，需维护者确认版权归属和署名后再落地为根目录 `LICENSE` 与包元数据。它允许广泛使用和修改，并要求保留版权和许可文本；完整条件以 [OSI 原文](https://opensource.org/license/mit) 为准。目前没有将建议当作已经授予的许可，也不对外宣称本仓库已完成开源授权。
2. **发布位置。** 可先公开现有 GitHub 仓库供源码安装；PyPI 名称占用、账户和上传另行核对。未经确认不变更仓库可见性、不创建公开 release、不上传 PyPI。
3. **公开材料。** 推荐首发只附合成示例和验证摘要。付费/受限行情与完整真实数据报告继续保存在仓库外。数据使用权不由代码许可证替代。

批准公开后，在拟发布的确定提交上再次运行包验收和敏感文件检查、确认新的 CI 通过，固定版本和包哈希，再发布。此清单不要求增加新的市场数据或大规模模拟后才能试用现有功能。
