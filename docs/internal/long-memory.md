# 长尺度相关：修正 R/S 对照

版本 0.11。此模块补充 Cont 第 8 项的评估，不输出“已证实长记忆”、Hurst 指数或幂律拟合。它回答一个较窄的问题：在选定窗口、带宽和渐近假设下，累计波动偏离是否与短期依赖参照不相容？

## 依据与选择

方法源于 [Lo (1991), Long-Term Memory in Stock Market Prices](https://doi.org/10.2307/2938368)。本轮核对了 [Gould, Porter & Howison (2016) 原文 Appendix B.3, pp.30–31](https://people.maths.ox.ac.uk/porterm/papers/long-memory-published.pdf) 中的修正统计量、临界值和带宽说明。该研究本身分析订单流；本库明确把同一统计工具应用于绝对收益，不照搬其市场结论。Lo 原始扫描件下载遇到 TLS/访问限制，没有声称完整通读其原文。

首版选择直接报告多个预设窗口的修正 R/S，而不对 ACF 的正值挑点做 log-log 回归。后者会丢失负值，拟合范围也很容易影响结论。这里不再把早期方案中的“拟合窗口”理解为必须输出一个幂律指数。没有统一的有限样本程序能仅凭一段市场数据证明长记忆；这项取舍作为方法边界保留。

## 输入、统计量与概率

每条资产/路径独立，先在 session 内按缺失收益断开。令一个连续窗口的 `x_t = |r_t|`，`y_t=x_t−mean(x)`，长度 n：

```
gamma_j = sum(y_t * y_(t-j), t=j..n-1) / n
S_q² = gamma_0 + 2 sum[(1-j/(q+1))*gamma_j, j=1..q]
R = max(cumsum(y)) − min(cumsum(y))
V = R / sqrt(n*S_q²)
```

累计和包含零起点与零终点。分母是长期方差估计，不是普通样本方差；协方差除以 n，不是 n−j。计算先缩放再中心化，避免原始收益单位导致上溢。方差为零或长期方差数值退化时不输出统计量。

参照分布为标准 Brownian bridge 的极差，极限 CDF 为
`F(v)=1+2 Σ(1−4k²v²) exp(−2k²v²)`。小 v 时使用等价的 theta 变换
`F(v)=sqrt(2π)*π²/v³ Σ k² exp(−π²k²/(2v²))`；大 v 时直接求 survival，避免 `1−F` 的消减误差。64 项足以在所选分支达到双精度；机器范围外的尾概率不作为精确零输出。

未修正双侧渐近 p 为 `2*min(F(V),1−F(V))`，上限 1。小于 `1e-300` 时记录该保守数值上界并标记，不表示真实 p 恰好等于它。95% 等尾参照区间约 `[0.809,1.862]`，由发表值和数值反演交叉核对。上侧拒绝可能反映持续性，下侧拒绝也不能直接解释为某种“反持久”机制。

## 窗口、带宽与资源

- 每个连续片段同时使用全段、两个半段、四个四分段。各窗口独立去均值，收益按结束时间归属；不跨 session 或缺口，日期范围逐行保存。太短的段仍列出原因，不拼成长序列。
- 默认 q 为 `0,10,20,40`，单位是基础收益观测数，不是固定秒数。q=0 只有独立序列参照意义，不参加排除短期依赖的检验计数。
- 每个组合要求 `n >= max(long_memory_min_points,20*(q+1))`，默认最低 512。门槛是工程约定，不保证矩条件、平稳性、带宽充分性或渐近精度。
- 同路径所有预设的非零 q × 窗口是一个比较族，包括不可计算项；可用 p 乘以族大小后截到 1。窗口相关不妨碍 Bonferroni 的代数上界，但实际错误率仍受原始渐近 p 的准确性限制。没有对多资产/路径作整体控制。
- 默认最多 128 个窗口、预计 2000 万个乘积；超限整项跳过，不挑选“最好”的片段。工作量估计为全部连续收益数 × 3 × Σ(q+1)。CLI 可以显式关闭或调整预算。

## 解释边界

极限参照需要稳定均值、适当的高于二阶矩条件与弱依赖/长期方差估计条件。有限 q 并不保证消除所有短期依赖；渐近理论中的带宽增长条件也不是四个固定默认值自动满足的。增大 q 可能吸收真正的长程相关而降低检验功效。结构断点、强重尾、长段缺失、报价沿用都会影响解释；没有自动检验这些条件。

全段拒绝而分段不拒绝，是继续检查状态变化的线索，不是已经识别断点的因果结论。各段都拒绝仍不足以证明长记忆。全不拒绝也不等于证明短记忆。ACF 图、描述性慢衰减和统计参照三者分开保留。

## 核对与导出

手算例 `[1,2,3,4]` 的 range 为 2，gamma0=1.25、gamma1=0.3125，q=1 得 V=0.8。另以 statsmodels 的常数均值 OLS + 无小样本修正 Bartlett 协方差独立核对分母；测试单位变化、时间倒序、缺口、常数、资源限额和数值尾部。固定波动断点的对照测试验证拒绝不会自动变成长记忆结论。

`long_memory.csv` 保存每个窗口的样本数、日期、q、统计量、原始/修正 p、数值上界标记及不可计算原因。JSON 中位于 `volatility_persistence.long_memory_test`。页面正文只说明问题和限制，明细折叠；保留全部窗口，不做显著点筛选。

小规模模拟见 `examples/validate_long_memory.py`：固定 N=4096、种子20261103，比较独立高斯收益、AR(1) 对数波动、H=.8 的 fGn 对数波动，以及只有方差断点的独立收益。fGn 用正半定循环嵌入生成，有限样本协方差与定义核对。只审计各单窗口的未修正渐近 p；不把它误称为报告的族错误率审计。参数保持不变，初轮及扩展结果均保留在 tmp。
