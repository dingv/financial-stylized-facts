# 生成第一份报告

本版回答十一组问题：价格和收益怎样变化、分布是什么形状、方向与波动是否持续、大涨大跌是否对称、拉长间隔后分布如何变化、平静和剧烈时段怎样交替、下跌后波动是否更大，较长范围的相关能否在不同时段重复观察、成交量是否与波动相伴，粗细尺度波动的先后关系，以及调整时变波动后的残差分布。它提供描述性结果，不自动判定某个市场“通过”全部金融事实。

## 准备价格文件

输入 CSV 至少有两列：

```csv
timestamp,price,asset_id,path_id,session_id
2024-01-02T09:30:00Z,100.0,example,run1,day1
2024-01-02T09:35:00Z,100.2,example,run1,day1
2024-01-02T09:40:00Z,100.1,example,run1,day1
```

这只是字段示例，三行不够进行可靠的统计分析。

- `timestamp`：明确的日期时间。带 `Z` 表示 UTC；没有时区时，必须传入 `--timezone`。
- `price`：有限且大于零的价格。默认拒绝缺失；显式添加 `--allow-missing-prices` 后保留空白价格及其缺口，不插值或删除。非数值、非正数、无穷大始终报错。
- `asset_id`、`path_id`：可选；缺省分别为 `series`、`observed`。每组单独计算，保留标识中的前导零。
- `session_id`：可选；同一组资产/路径内，一个值代表一个连续交易段。午休前后或闭市前后可以分段，不能重复用同一个标识表示不同交易段。

不要把实际缺失的交易日直接删除后当作连续日频序列。当前没有交易日历，也不直接读取收益率。区间成交量可选，需按下面的约定明确声明。

## 高频或分钟数据

```bash
fsf analyze prices.csv --output /tmp/my-fsf-report \
  --frequency 5min --timezone Asia/Shanghai \
  --max-staleness 30s --price-type transaction
```

这里每五分钟取一次价格，允许使用该时刻之前最多 30 秒内的最后价格；更旧则留缺失。`30s` 只是示例，应按数据频率决定。默认 `--max-staleness 0s` 只接受精确网格端点，不默认无限沿用旧价。

收益是相邻网格价格的对数差，不重叠；任一端点缺失，该收益就缺失。网格以 UTC 的固定时间边界对齐，范围限于每段实际观测的起止时间。同一时间的多条记录按原文件行顺序取最后一条，并在报告说明。

没有 `session_id` 时，默认按指定时区的日期分段（未指定则 UTC），不计算跨日收益；这只是保守默认，不能代替交易所日历。跨夜连续市场或模拟轨迹可以提供明确的 session，或在确认数据确实连续时选择 `--session-policy continuous`。午休、周末或长缺口需要明确分段与合理的沿用上限。

## 已整理的日收盘价

```bash
fsf analyze daily.csv --output /tmp/my-daily-report \
  --sampling observations --observation-unit trading-day \
  --timezone UTC --price-type close
```

这个模式按每个交易日的观测顺序计算，不插入周末。lag 1 是相邻交易日，不能解释成固定 24 小时。使用前需自行核对交易日是否齐全；当前程序无法识别漏掉的交易日。不要给每行分配不同的 session，否则无法计算相邻日收益；确有断档需要隔断时，再指定新的 session。

## 怎么读结果

打开 `index.html`，从下拉框选择资产或路径。每组分别展示价格与收益、收益密度、收益/绝对收益/平方收益的 ACF。密度图不混合路径、不叠加正态参照；峰度从样本直接计算。

每条路径先给三条观察摘要：分布、相邻相关和数据覆盖。每幅图前的浅蓝文字直接引用当前路径的计算结果；说明不等于“通过”或“显著”。例如 GARCH 比较只使用同段、同范围的峰度，样本不足会直接说明。数据来源和较长的方法说明可以展开查看。

相邻相关固定看 lag 1，长范围相关固定看配置终点，多尺度摘要固定比较首尾尺度；不会挑最有利的点。如果单条观测贡献了超过一半的四次方偏差，正文会提醒峰度对这条观测敏感。这只是阅读提示，不是异常值删除规则或统计检验；所有数据仍保留。

ACF 横轴在固定网格模式中标为实际时长。例如五分钟收益的 lag 2 对应十分钟。日频观测模式标为观测次数，并在页面写明单位。默认最多 30 个 lag；`--max-lag` 可调整。`--min-pairs 20` 表示配对不足的点留空，这个门槛不是显著性保证。

部分分布与量价统计已有重采样区间；早期 ACF、收益与波动相关和粗细方向差值有 HAC 近似区间。长尺度部分另有修正 R/S 的条件性短期依赖检验；尾指数尚未提供。正超额峰度、连续正相关都是需要结合样本量解释的线索。不能把高峰度直接写成已经证明幂律厚尾，也不能把几个相关点或一次拒绝称为已证实长记忆。

## 新增的三个诊断

**涨跌不对称。** 左右尾柱图比较偏离本路径均值 1、2、3 个标准差的概率，另给修正偏度。新增首达时间图回答“达到相同涨跌幅需要多久”：默认阈值为 ±1、2、3 个基础收益标准差，观察 20 个基础间隔。不去趋势；上涨和下跌各自寻找首次命中，同一起点可以先后达到两边。

主曲线使用同一组具备完整窗口的起点；窗口内未命中的也计入分母。数据末尾、缺口或 session 边界导致观察中断的起点另行计数，并给出不假设未知后续走势的比例界限，**它不是置信区间**。观察窗口重叠，不把这些起点当独立样本做检验。展开附录还可看连续片段内最大回撤与回升、原始收益分位数和同号涨跌段；这些回答不同问题。

```bash
fsf analyze prices.csv --output /tmp/report-first-passage \
  --frequency 5min --first-passage-horizon 24 \
  --first-passage-unit log_return --first-passage-thresholds 0.005 0.01 0.02
```

这表示最多观察 24×5 分钟，比较三个明确的对数收益阈值；它们不等于严格的 0.5%、1%、2% 简单收益。使用 `--first-passage-unit sigma` 时阈值为本路径全样本标准差的倍数，属于回顾性尺度。完整起点不足 `--first-passage-min-starts`（默认 20）则主图留空；`--first-passage off` 可关闭。方法与截断计数见[首达时间说明](internal/first-passage.md)。

**多尺度分布。** 默认比较基础间隔的 1、5、10、20 倍。例如基础间隔为 1 分钟，就是 1、5、10、20 分钟收益。日频观测模式则是 1、5、10、20 个交易日。按每段首个采样价格固定起点，不重叠相加对数收益；块内有缺失则整块无效，结尾不足整块就舍弃，不为凑样本移动分组起点。图中给峰度和标准化分位数相对高斯的距离，表中列出样本数。分位数距离只看 1%–99% 的等距概率点，不能代替远尾检验，也不是 p 值。

**间歇性。** 滚动 RMS 展示平静与剧烈时段。另用全路径均值、标准差定义大幅变化，记录出现次数和连续片段长度；缺口与交易段边界断开片段。这是描述规则，不把长期漂移或外部时段变化自动解释成内生机制。

例如在一分钟基础采样上，比较 1、5、15、60 分钟收益，用最近 30 个收益算 RMS：

```bash
fsf analyze prices.csv --output /tmp/report-scales \
  --frequency 1min --timezone UTC --price-type midquote \
  --aggregation-factors 1 5 15 60 --rms-window 30 --burst-threshold 3
```

沿用价格的时长仍需按数据情况单独设置。聚合倍数必须从 1 开始严格递增；默认窗口和阈值是可调整的工程约定，不是 Cont 为所有市场指定的参数。

## 收益与前后波动，以及较长范围的相关

**杠杆效应图。** 正 lag 表示当前收益对应未来波动，负 lag 表示对应过去波动。平方收益和绝对收益分别作为波动代理。每个 lag 使用有效配对重新计算 Pearson 相关，零方差或配对太少就留空；lag 0 是同期关系，不表示先后。负的正滞后相关是一种杠杆效应线索，不自动作因果解释。外汇倒数报价会反转收益与相关系数的符号。

**较长范围的 ACF。** 默认延长绝对收益 ACF 到 300 个基础间隔，并将路径按时间排序后的观测槽等分为 4 段，各段独立计算。它能帮助区分全程状态变化与更稳定的局部现象；不同分段的时间跨度可能不同，尤其是跨交易日时。不会跨 session 或诊断分段配对，不移除缺口来压缩 lag；边界前后差分产生的收益仍归到其结束时刻，分段 ACF 不跨边界配对。

```bash
fsf analyze prices.csv --output /tmp/report-dependence \
  --frequency 1min --timezone UTC --price-type transaction \
  --max-lag 30 --volatility-max-lag 300 --stability-blocks 4
```

这里收益 ACF 与杠杆效应看到 30 分钟，长范围波动 ACF 看到最多 300 分钟。分段或交易时段不足以支撑的 lag 不会被外推。每段独立去均值且样本更少，图中的差异也可能来自配对覆盖率；应结合导出的配对数理解。多日数据的固定日内季节性并没有自动去除。

本版不删除负 ACF 点来拟合直线，不自动给出 Hurst 指数、幂律指数或长记忆判定。正式长记忆检验仍待增加。

**怎样读区间。** 早期相关图中的淡色区间是近似的单项 95% 区间，表示估计的不确定性，不是“零相关”的水平参照带。没有区间的位置可能是样本不足，而非没有不确定性。方法依赖短记忆、稳定矩等条件，强远尾或状态变化会影响可靠性；展开报告附录可看全部带宽、原因和多重比较区间。

默认 `--dependence-inference hac --inference-max-lag 10 --hac-bandwidths 10 20 40`。主图固定第一种带宽，不根据结果切换。多重比较区间针对同一路径中计划的指标、滞后及带宽组合，不覆盖跨资产比较。粗细方向差值的 lag 和带宽单位均为粗区间；其他指标使用基础间隔。可用 `--dependence-inference off` 关闭。计算有每路径工作量上限，超限会说明原因，不暗中缩短输入。

详见[HAC 计算约定](internal/dependence-inference.md)。这些区间不适用于后面的长范围 ACF 或拟合后 GARCH 残差，不能据此声称长记忆已经通过检验。

## 成交量与波动

CSV 可添加 `volume` 列，表示**结束于这一行时间戳的基础区间成交量**。例如一分钟数据中，09:31 的量对应 (09:30, 09:31]，与这一分钟的收益配对。金额、股数、合约数等单位必须明确，不把成交笔数或报价次数默认当作成交量。

```bash
fsf analyze bars.csv --output /tmp/report-volume \
  --frequency 1min --volume-kind interval --volume-unit shares \
  --price-type close
```

当前只接受已经按分析频率汇总好的区间量，**不自动把逐笔量、累计量或一分钟量转换为五分钟量**。grid 模式的所有输入行必须位于对应 UTC 网格端点，且同一资产/路径/session 内时间戳唯一；即使时间戳对齐，也需要你保证 `volume` 覆盖的确实是所声明区间，程序无法从数值推断覆盖时长。切换频率时应先重新汇总输入。日频 observations 模式的量属于当前交易日，与截至该日的收益配对；收盘至收盘收益可能包含隔夜变化，量价时间覆盖的局限应结合市场解释。

量缺失请留空，真实零成交量填 0。缺失量不沿用、不插值；即使价格按允许时长沿用，量也仍然留空。首个价格没有对应收益，其成交量不参与相关计算。没有 `volume` 列则不需要以上参数，报告会明确跳过该项；有列却不声明含义会报错，避免误用。

图按量的分位数形成最多五组，相同量不拆组，展示组内平均绝对收益与样本数；相关系数从原始配对区间计算。Pearson 看线性关系，Spearman 看排序关系。适用时在区块重采样输出中提供近似区间；尚未去除日内季节性，不把相关解释为因果。

## 粗细尺度波动的时间方向

```bash
fsf analyze prices.csv --output /tmp/report-timescale \
  --frequency 1min --coarse-factor 30 --max-lag 10 --price-type midquote
```

这组设置把每 30 个一分钟收益组成一个不重叠区间：粗波动为整段净收益的绝对值，细波动为段内一分钟绝对收益的平均值。左图分别看“粗波动在前、细波动在后”和相反顺序；右图是后者减前者，负值表示粗在前的相关更强。横轴一步是 **30 分钟**，10 步是 300 分钟；同一参数下普通收益 ACF 一步仍为 1 分钟，不要混淆。

默认粗细比例为 30，可用 `--coarse-factor` 调整。这是工程默认，不是适用于所有市场的固定标准。比如五分钟基础采样配合 factor 6，就是五分钟与三十分钟的对照。日频 observations 模式对应基础观测与连续若干交易日，不意味着固定日历时长。

块内缺失会使整块无效，尾部不够一块就舍弃，不跨 session。配对不足或波动恒定留空；只剩同期相关也不能称为观察到时间不对称。这项与幂律缩放不同，也不是因果或预测能力检验。

## 条件厚尾：先调整时变波动

已配置的项目 Conda 环境包含 `arch`。其他环境安装本库时，可用 `python -m pip install '.[conditional]'` 添加可选依赖；不安装也能分析其余项目，报告会说明条件厚尾不可用。

默认 `--conditional-model auto`：在每个 session 内按缺失收益切成连续段，各段独立拟合常数均值 Gaussian QMLE GARCH(1,1)。它用时变条件波动调整收益，再比较原始收益与标准化残差。原始与残差使用同一段、同一范围，密度分别画，不拼接段。图中的高斯是拟合准似然假设，不代表强制把观测残差变成正态；残差是否仍厚尾是待观察结果。

```bash
fsf analyze prices.csv --output /tmp/report-conditional \
  --frequency 1min --conditional-model auto \
  --garch-min-points 500 --garch-max-points 100000 \
  --garch-max-segments 8 --garch-max-iter 500 --garch-burn 50
```

这些是可配置的样本与资源门槛，不是普遍的统计充分性保证。按时间顺序尝试完整段，超过每条路径的总样本/段数限制就标记跳过，不自动截断长段。报告同时列出所有短段、失败段和超限段，披露真正进入残差比较的覆盖率，不能将少数成功拟合段概括为全路径结论。用 `--conditional-model off` 可显式关闭。多资产运行的资源随路径数增长，默认限制按路径生效。

先做显式中心化、缩放，拟合参数再恢复原单位；优化未收敛、方差无效时不输出残差统计。每段拟合后舍弃开头 50 个观测作初始化敏感性缓冲，原始分布也舍弃相同位置。高持续性模型的初始化影响可能超过 50 个观测，程序会提示，但这并不替代敏感性验证。

右图对照原始中心化收益的平方 ACF 与标准化残差平方 ACF。如果后者仍有明显相关，说明该模型还可能遗漏结构。参数在零边界或持续性接近 1 时另给提示；残差峰度不是拟合充分性或厚尾显著性的检验。这里使用全段样本内拟合，不提供交易预测或样本外效果结论。

## 估计有多稳定？

默认对分布与部分量价统计量给出**区块重采样的近似 95% 区间**。比如峰度估计为 3，并不表示换一段同类样本仍精确等于 3；区间和块长对照帮助看出这种不稳定性。

```bash
fsf analyze prices.csv --output /tmp/report-intervals \
  --frequency 1min --bootstrap-reps 399 \
  --bootstrap-block-lengths 10 20 40 --bootstrap-seed 20261103
```

一块包含若干连续基础收益，一起抽取以保留部分时间依赖。每个连续段分别重采样，缺口、session 和资产之间不互相接块；循环只发生在本段内部。块长 10/20/40 是可调整的默认设置，不是通用最佳选择。页面保留三种结果，数据不足的方案会说明原因；一分钟基础采样的块长 20 是 20 分钟，日频观测模式则是 20 个观测。

范围包括均值、标准差、偏度、峰度、尾部/零收益比例和量价相关。每次重新计算统计量；量和收益一起抽，不能独立打乱。原始统计量、区间、重采样标准误、有效重复数与种子保存在 `uncertainty.csv`。没有观察到某类事件时，重采样可能始终为零；这种情况标为退化，不会宣称未来发生概率为零。

少于 200 个有效收益时不计算；每种方案要求每个连续段至少两块、全路径至少二十块。默认工作量上限为每路径收益数 × 重复次数 × 块长方案数不超过 2000 万；超限会显示原因。`--bootstrap-reps 0` 关闭，`--bootstrap-max-work` 可调整上限。建议先看数据覆盖和机器资源，再提高重复次数。

区间假设段内近似平稳、依赖不会无限持续，并满足相应矩条件；强远尾尤其可能使峰度区间失真。它固定已观察到的交易段与样本量，不包含市场状态更替的不确定性。不同块长差异大时应保留差异，不能选择看起来最支持结论的一组。

**区间不是统一的显著性检验。** 这里没有施加零假设、没有 p 值，也没有对多资产/多指标做同时置信校正。ACF、杠杆效应、尺度差值使用前述独立的 HAC 方案；GARCH 参数、条件残差和首达时间不适用这组边际重采样区间。

## 长尺度相关的辅助检验

默认在绝对收益上计算 Lo 修正 R/S，比较完整连续段、半段和四分段，以及 q=0/10/20/40 四个带宽。q=0 只作独立序列参照；其他带宽用于考虑短期相关的影响。结果在长范围 ACF 下方，全部数值导出为 `long_memory.csv`。

```bash
fsf analyze prices.csv --output /tmp/report-persistence \
  --frequency 1min --long-memory-bandwidths 0 10 20 40 \
  --long-memory-min-points 512
```

一分钟收益的 q=20 表示考虑 20 个一分钟间隔内的相关；日频观测模式则是 20 个观测。每个窗口还需不少于 20(q+1) 条连续收益。短片段会显示样本不足，不压缩缺口或拼接不同交易时段。`--long-memory off` 关闭辅助检验，ACF 图照常保留。

**拒绝不等于证实长记忆。** 报告提供单路径内多重比较修正，但渐近近似仍受矩条件、状态变化和带宽影响；不拒绝也不证明没有长期依赖。默认最多 128 个窗口、预计 2000 万工作量，超限整项说明原因。公式、选择和局限见[技术说明](internal/long-memory.md)。
