# 金融典型事实：指标与结果解读

这份文档配合统计评估报告阅读。报告回答“这条价格序列呈现了什么”，这里解释“为什么用这些指标，以及数字应当怎样理解”。同一套方法适用于真实行情和模拟价格。

## 从价格到报告

输入价格 → 明确采样间隔 → 计算收益 → 分别评估 11 项事实 → 输出图表与统计量。

首先确定价格代表什么：成交价、中间价和复权收盘价会保留不同的市场信息。股票长期序列通常需要处理拆股等公司行动；汇率还要明确报价方向。每个资产、每条路径分别计算，报告中的数字不来自不同路径的混合。

收益采用对数价差：

```text
r[t] = log(P[t] / P[t−1])
```

价格由 100 变成 101，对数收益约为 0.00995，即 0.995%。把五个相邻一分钟对数收益相加，就得到对应的五分钟对数收益。报告使用不重叠区间。

**收益间隔与 lag 要分开。** 如果基础收益是五分钟收益，ACF 的 lag 1 比较相隔五分钟的两个收益，lag 3 则相隔十五分钟。日频观测模式的一步是一个源观测，周末不会自动变成零收益；它也不一定等于 24 小时。

## 如何读总览

总览的“结论”来自固定、可追溯的规则，不调用大模型。每项同时标明证据类型：

| 类型 | 含义 |
| --- | --- |
| 区间证据 | 具体方向得到本次近似区间的支持，或完整检验范围未检出相关 |
| 描述性结果 | 图形和点估计呈现某种现象，尚无相应的一致区间证据 |
| 未评估 | 缺少必要数据、样本不足、指标不可计算或模块未启用 |

例如，“有厚尾迹象”比“超额峰度为正”多检查了尾部计数；“厚尾指标有支持”还要求两项指标在所有配置块长下的区间方向一致。它描述的是本样本的有限阈值尾部，并没有估计幂律尾指数。

“未检出线性相关”表示所检范围的区间包含零；要证明相关小于某个实际容忍范围，需要另设等效性判据。本库当前不把未拒绝零相关称为独立性证明。

以下按 Cont 的顺序解释各项。实现中的精确公式见[统计方法](methods.md)，输入与参数见[使用指南](usage.md)。

## 1. 收益线性相关较弱

问题是：刚刚上涨之后，下一段是否也倾向上涨？收益 ACF 衡量线性关联。正相关意味着同向变化更常相伴，负相关意味着相反方向更常相伴。

完整序列的常用固定分母估计为：

```text
ACF(k) = Σ[t=k+1..n] (r[t]−平均收益)(r[t−k]−平均收益)
         / Σ[t=1..n] (r[t]−平均收益)²
```

用 `[1, −1, 1, −1]` 举例，均值为 0，分母是 4，lag 1 的分子是 −3，因此 ACF(1)=−0.75。这里使用固定分母，和把三对观测另算 Pearson 相关的结果不同。ACF(0) 恒为 1，报告省略这一点。

报告既给出 lag 1 的数值，也检查预先配置的早期滞后范围。一次相邻负相关可能来自买卖报价反跳；它不能自动推出长时间可预测性。

## 2. 厚尾

问题是：较大的标准化收益，是否比高斯参照下更常出现？先将收益减去自身均值，再除以自身标准差，得到 `z`。

报告主要看两个量：

- **超额峰度**：标准化四阶中心矩减 3；高斯分布基准为 0。四次方使极端观测获得很大权重。实际报告使用有限样本修正版本。
- **3σ 尾概率**：`|z| > 3` 的收益数除以全部有效收益数。标准高斯参照约为 0.270%。

峰度不是概率密度曲线中心点的高度。大量很小的变化夹着少数中等变化，也可能产生正超额峰度，却没有很远的尾部。因此报告要求同时看峰度和尾部计数。KDE 只是平滑展示；计算峰度时直接使用收益样本。

如果一次变化占四次方偏差总量的一半以上，报告注明其贡献比例。保留该观测，不为了让图形“正常”而删除它。进一步研究远尾时，可查看导出的尾概率与 Q-Q 图。

## 3. 涨跌不对称

这里包含两种不同问题：

**分布是否左右不对称？** 偏度为负常表示左尾影响较大，为正常表示右尾影响较大。左右尾图围绕样本均值比较同一标准差阈值，和上涨次数占比不同。偏度区间若跨零，就不能仅凭其点估计的符号判断稳定不对称。

**达到同样大小的涨幅、跌幅，需要多久？** 首达时间图从各个起点分别等待价格达到 `+a`、`−a` 对数收益。某条曲线上升更早，表示更多起点较早达到该方向阈值。两侧使用同一组完整后续窗口；未命中的起点仍在分母里。一个起点可以先后到达两侧，所以两边比例不必加起来等于 100%。

首达时间结果也会受到漂移、阈值和观察窗口影响。总览的区间结论针对偏度；首达时间在正文单独描述，没有把两者合成一个显著性检验。

## 4. 聚合高斯化

问题是：把收益间隔拉长，标准化分布是否更接近高斯？例如比较 1、5、10、20 个基础间隔。

报告观察超额峰度离 0 的距离，以及选定分位数与高斯分位数的 RMSE。两者从配置中的最短尺度到最长尺度都下降，才标为“有聚合高斯化迹象”；中间尺度发生反复会写出。它不等于最长尺度已经服从正态。

间隔越长，可用收益通常越少。规则要求每个配置尺度至少 100 条收益才给趋势结论；这是本库的描述性样本门槛，不是论文的通用常数。不会跳过不理想或不足的尺度，另挑一个好看的终点。

## 5. 间歇性

问题是：平静与剧烈变化是否交替出现？滚动 RMS 是一个直观视角：

```text
RMS = sqrt(最近 W 个收益平方的平均值)
```

RMS 高表示这一段变化较大，低表示较平静。它不减局部均值，所以持续漂移也会抬高 RMS。

另记录超过指定标准差阈值的大幅变化，以及连续超阈值片段的数量和长度。出现几个片段本身不足以构成间歇性的正式检验，因此本项总览保持描述性结论，由时间图展示形态。

## 6. 波动聚集

问题是：大的变化之后，是否还容易接着出现大的变化，而不论涨跌？分别对 `|r|` 和 `r²` 计算 ACF。

例如收益正负交替，普通收益相关可能为负；但如果绝对幅度连续较大，绝对收益 ACF 仍可能为正。平方收益更强调大的变化，因此两条曲线不必完全一致。

总览的“短期波动聚集有支持”要求：在所检早期滞后范围，两种代理至少在两个连续滞后都有正相关区间支持，且各个配置带宽一致。只有一个共同正点，写为“局部正相关”。这是本库固定的操作规则，不是 Cont 给出的数值定义。

固定日内高波动时段也可能形成相关。当前结论针对输入序列；没有默认去除日内季节性。

## 7. 条件厚尾

问题是：厚尾是否仅仅来自“不同时间的波动大小不一样”？本库用 GARCH(1,1) 描述条件波动：

```text
e[t] = r[t] − mu
sigma[t]² = omega + alpha × e[t−1]² + beta × sigma[t−1]²
标准化残差 z[t] = e[t] / sigma[t]
```

在同一时间范围比较原始收益与残差。如果残差仍同时呈正超额峰度和偏高的 3σ 尾概率，则保留“残差仍有厚尾迹象”。同时看残差的平方 ACF：残留相关可能说明这个波动模型还不充分。

每个连续段单独拟合和展示，缺口前后不拼接。总览列出进入残差比较的样本数，防止把少数可拟合片段当成整条路径。没有计算拟合后尾部的区间，因此本项仍是描述性结论。

## 8. 波动相关缓慢衰减

问题是：波动的相关是否延续到比前几步更长的范围？报告提供长范围绝对收益 ACF，以及按时间分段的对照。若全程持续为正、分段后消失，要考虑波动状态变化的作用。

Lo 修正 R/S 检查累计偏离相对于短期相关调整后方差的大小。多个窗口和带宽同时报告，非零带宽组合的渐近 p 值做 Bonferroni 修正。`q=0` 仅作独立序列参照。

拒绝短期依赖参照，仍可能来自结构变化或未充分调整的相关。当前程序没有拟合 ACF 的幂律衰减指数，因此总览不会把这些结果自动写成“长记忆已证实”。

## 9. 杠杆效应

比较当前收益与以后绝对收益、平方收益的相关：

```text
corr(r[t], |r[t+k]|) 或 corr(r[t], r[t+k]²), k > 0
```

负值表示较低的收益与更大的后续波动相伴。两种代理在同一正滞后、所有配置带宽下均有负向区间支持，报告才写“负向关系有支持”。这仍是相关关系。

外汇报价倒过来时，`log(1/P)` 的收益符号反转，杠杆相关也反号；比较不同市场前应核对报价方向。

## 10. 成交量与波动相关

问题是：交易量大的区间，价格变化是否也更大？Pearson 描述线性关联，Spearman 描述排序上的单调关系。量分组图辅助展示二者的关系，相关系数使用原始区间配对计算。

当成交量与绝对收益的两个系数，都在所有配置块长下取得正区间支持，才给“量价正相关有支持”。点估计同时为正而区间不足时，保留“有正相关迹象”。缺少成交量时本项不适用。

输入必须是相应区间的真实成交量；报价次数、价格条数和累计成交量不能直接代替。股票使用复权价格时，还要记录量是否作过拆股调整。

## 11. 时间尺度不对称

把每 `m` 个基础收益组成一个不重叠块，计算：

```text
粗尺度波动 C[t] = |块内收益之和|
细尺度波动 F[t] = 块内绝对收益的平均值
D(k) = corr(F[t], C[t+k]) − corr(C[t], F[t+k])
```

粗尺度看整段净变化，细尺度看段内每一步的变化大小。若 `D(k)<0`，粗波动在前的相关更强；若大于 0，细波动在前更强。区间跨零时，先后方向差异尚不明确。两种符号在不同滞后分别有支持时，总览注明方向随滞后变化。

这里一步是一个粗区间。例如基础一分钟、`m=30` 时，lag 2 表示两个粗区间相隔一小时。它不是价格变化随时间间隔的幂律缩放检验。

## 区间怎样参与结论

**分布和量价指标**采用连续有效段内的循环区块重采样。默认每种块长重复 399 次，块长为 10、20、40，得到单项 95% 百分位区间。每次重算均值、标准差和对应指标。保留每个方案，不选最有利的块长。

**时间相关指标**采用线性化加 Bartlett HAC 标准误。默认检查前 10 个滞后、带宽 10、20、40，另提供本路径所有计划指标／滞后／带宽组合的 Bonferroni 校正区间。总览使用校正区间并要求所有配置带宽方向一致；图中阴影使用固定第一种带宽的单项区间。所以仅凭某张图里一个阴影不跨零，未必达到总览判据。

区块法和 HAC 都是依赖一定平稳性、弱依赖与矩条件的近似方法。强远尾、长记忆或结构变化会影响它们。分布与量价的区间没有做跨 11 项、跨资产联合校正，报告也不汇总“通过几项”。

计算失败、有效重复不足或任一所需敏感性方案缺失，都不能当成支持证据；关闭推断仍可保留描述性结果。

## 可编程使用与复核

```python
result = analyze_csv("prices.csv", "/tmp/report", config)
for group in result["groups"]:
    for fact in group["assessment"]["by_fact"].values():
        print(group["asset_id"], fact["name"], fact["label"], fact["metrics"])
```

`assessment.csv` 与 HTML 使用同一份结果。`conclusion` 表示具体结论，`evidence_level` 表示区间、描述或不可评估，`computation_status` 表示底层计算状态，`rule_id` 标识规则版本。不要把所有 `supported` 加起来当作市场总分；例如第 1 项“检出相关”恰好指出与低线性相关事实的差异。

各项原始统计、区间、样本量和原因保存在 `results.json` 与对应 CSV；旧版 `findings` 和 `observations.csv` 仍保留，便于已有代码继续使用。数值估计器没有因本次报告改版而改变。
