# 第一轮真实市场验证

这轮确认了：同一套入口能分析日频外汇、股票与分钟级 EBS 价格；缺少成交量、连续样本不足或区间无法估计时，会明确说明原因。**这验证了数据处理和计算流程，不代表所有市场都“通过”了十一项事实。**

使用两组日频汇率、两只股票，以及两组汇率的一分钟／五分钟样本，共八份独立报告。没有合并不同资产的收益，也没有挑选更好看的路径。

## 数据与观察

日频范围均为 2000-03-01 至 2013-03-01，每份得到 3269 条相邻有效报价的对数收益。股票使用 Bokeh 样本的调整收盘价，FRED 是纽约中午汇率；下面不是同口径资产排名。

| 日频样本 | 超额峰度 | 相邻收益 ACF | 相邻绝对收益 ACF |
| --- | ---: | ---: | ---: |
| EUR/USD（FRED） | 2.10 | 0.011 | 0.018 |
| USD/JPY（FRED） | 4.11 | −0.034 | 0.078 |
| AAPL | 105.69 | −0.032 | 0.177 |
| MSFT | 9.13 | −0.049 | 0.247 |

这几份样本的收益方向线性相关较小，而部分样本的波动大小相关更明显。表中都是点估计，不把正值自动解释成显著性或长记忆。

**苹果的 105.69 需要单独解释。** 样本中 2000-09-29 的对数收益约 −0.732，未调整的 Close 列也有近似幅度；这不是仅从 Adj Close 一列冒出来的跳变。本轮保留了它，没有删掉大跌来修饰分布。三个块长下峰度的近似 95% 区间分别约为 [2.55, 169.28]、[2.97, 172.08]、[2.89, 177.75]。区间很宽，说明少数极端观测会强烈影响这个统计量；此处仍需注意高阶矩与重采样假设，不能把 106 当成稳定的市场常数。事件背景及公司行为未做独立行情审计。

EBS 样本覆盖 2026-07-29 21 点后至次日 21 点前，只是一份文件日。网格向后取价，最长沿用五分钟；不把报价行当成交，不用未来价格补齐。

| EBS 样本 | 有效收益数 | 超额峰度 | 缺失网格价格数 |
| --- | ---: | ---: | ---: |
| EUR/USD，1 分钟 | 1258 | 7.41 | 156 / 1436 |
| EUR/USD，5 分钟 | 248 | 2.74 | 28 / 287 |
| USD/JPY，1 分钟 | 1272 | 46.04 | 144 / 1436 |
| USD/JPY，5 分钟 | 243 | 44.23 | 31 / 287 |

两个五分钟样本的相邻绝对收益相关约 0.32，呈现短期波动持续的描述线索。但是样本只有一天，还有缺口与沿用价格，不能据此认定长期性质。一分钟样本零收益约占 34%–35%，其中可能包含沿用价格的贡献；这也说明采样规则必须写在报告里。

## 数据不足时怎样处理

四份日频样本完成 GARCH 拟合。EBS 一分钟样本只在足够长的连续段拟合，进入残差比较的收益分别为 688/1258 和 613/1272，不能概括成整天结果。五分钟样本不足配置要求，全部跳过。

日频样本完成区块重采样区间。EBS 的短连续段无法满足当前块长条件，区间标为不可计算；没有悄悄删掉短段或改小块长来获得结果。外汇输入未提供量，因此量价模块跳过；股票量价模块可运行，但样本提供方的成交量调整口径未独立审计。

FRED 选择了“相邻可用报价”的时间轴，范围内各移除 123 个无价格日期。如果保留这些缺失槽，有效收益会从 3269 降至 3146。这是明确的研究口径选择，不是把缺失处理视作无影响；lag 也不代表固定 24 小时。

## 验证证据与下一步

130 项测试通过。八份报告另用独立的 NumPy 向后查价、差分与直接求和，以及 SciPy 修正峰度进行复核：有效收益数和缺口数完全一致，ACF 最大绝对误差小于 2.3×10⁻¹⁶，峰度误差小于 2.9×10⁻¹⁴。所有源文件前后哈希一致。整轮约 17.5 秒，临时输出约 18.3 MB。

这仍是第一轮小规模验证。下一步重点是完善报告中的自动观察摘要、方法适用性与时间相关指标的不确定性；真实数据的日历、复权和季节性也需继续作为显式限制保留，不靠追加漂亮样本代替这些工作。

字段、来源及转换方式见[真实数据指南](data-guide.md)。完整报告在临时目录，不随 Git 分发；重跑脚本是 `examples/validate_real_data.py`，独立数值审计是 `examples/audit_real_validation.py`。这轮临时路径记录在内部执行记录中。
